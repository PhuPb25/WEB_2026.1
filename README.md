# Portfolio Trần Anh Phú

Website giới thiệu cá nhân, viết bằng HTML/CSS/JavaScript thuần.

## Chạy trên máy
Mở `index.html` bằng trình duyệt, hoặc dùng VS Code + Live Server.

## Đưa lên GitHub Pages
1. Tạo repository public, ví dụ `portfolio`.
2. Upload toàn bộ file/thư mục trong project.
3. GitHub → Settings → Pages.
4. Chọn Deploy from a branch → `main` → `/ (root)` → Save.
5. Sau khi site chạy, vào Custom domain và nhập:
   `phuta235397.id.vn`
6. Ở nơi quản lý DNS của domain, thêm các A record GitHub Pages theo tài liệu chính thức của GitHub.

## Thay ảnh
Thay `assets/profile.jpg` bằng ảnh cá nhân của bạn.

## Thay thông tin
Chỉnh nội dung trực tiếp trong `index.html`.
